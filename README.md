# TALLERS VALLÈS — Mechanic

* Made by **Roger Pla Ballús** with **Gemini 4 Argon**

## Stack
* **Markup:** Semantic HTML5 (`<dialog>`, `<details>`, native `<input type="date">`)
* **Styling:** CSS3 Custom Properties + Grid + Tailwind CSS v4 CDN (zero glow/shadow effects)
* **Logic:** Vanilla ES6+ JavaScript (`Intl.NumberFormat`, zero runtime dependencies)
* **Graphics:** Inline technical SVGs + single optimized Pexels WebP/JPEG asset

## Architecture
* **Single-File SPA (`index.html`):** Zero build step, zero bundler, zero external state libraries
* **Pure State Engine:** Deterministic `computeQuote()` reducer with `O(n)` calculation
* **Trust Boundary Layer:** Input sanitization (`sanitizeText`) + EU/Spanish license plate regex validation
* **Embedded Self-Test Runner:** Automatic load-time assertions verifying EUR/IVA math and XSS stripping

## Core Highlights
* **Catalonia Context:** Sabadell workshop specs, Applus+ Pre-ITV telemetry, 21% Spanish IVA math
* **Strict Bulletpoint UI:** Zero filler prose, zero duplicated contact info, high-contrast Swiss industrial grid
* **Dual Contrast Modes:** Instant switch between *Daylight Floor* and *Inspection Pit* themes

## Install / Run
* **Download:** `git clone <repo-url>` or download `index.html` directly
* **Run Locally:** Open `index.html` in any modern browser or run `npx serve .`
